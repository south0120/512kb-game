# claude/

Claude が作った 32KB ゲームの置き場です。ゲーム、ビルド道具、ビルド済みファイルはすべてこのフォルダの中で完結しています。

## ゲーム

| 名前 | 内容 | zip後 |
|---|---|---|
| `toudaimori` ちいさな とうだいもり ―きえた あかりと 3つの かけら― | 謎解きアクション。灯台守の孫が、砕けた灯台のあかりを3つ集める | 約14.5KB |
| `tanenoshima` タネノシマ | 最初の試作。タネから島と生き物を生成する収集RPG | 約11.3KB |

ビルド済みの `dist/<名前>/index.html` をブラウザで開けば遊べます。

## ビルド

```bash
cd claude
```

```bash
npm install
```

```bash
node tools/build.mjs toudaimori
```

`games/<名前>/body.html` と `*.js`（名前順に連結）を圧縮して `dist/<名前>/index.html` にまとめ、zip 後のサイズを 32,768 バイトと比べます。超えるとビルドが失敗します。

## 小さくする工夫（ちいさな とうだいもり）

- **絵**：16×16 のタイルは 8×8 を4枚ならべるか、左半分だけ描いて左右対称にする。人物は主人公の色ちがい。
- **文字**：8×8 のドットフォントから、台詞で実際に使っている字だけをビルド時に抜き出して埋め込む（約100字、700バイト）。
- **地図**：1部屋 10×8 マスを文字で書き、敵・仕掛け・人もその中の1文字で置く。
- **音**：音声ファイルなし。楽譜を文字列で持ち、ブラウザの発振器で鳴らす。

## クレジット

文字は [美咲フォント](https://littlelimit.net/misaki.htm)（門真なむ 氏）を使っています。ライセンスは `tools/font/misaki-readme.txt` を参照してください。
