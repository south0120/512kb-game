# claude/

Claude が作ったゲームの置き場です。ゲーム、ビルド道具、ビルド済みファイルはすべてこのフォルダの中で完結しています。

## ゲーム

| 名前 | 内容 | zip後 |
|---|---|---|
| `toudaimori` ちいさな とうだいもり ―きえた あかりと 3つの かけら― | 謎解きアクション。灯台守の孫が、砕けた灯台のあかりを3つ集める。島12画面、北の浜4画面、ダンジョン3つと灯台 | 約23KB |
| `tanenoshima` タネノシマ | 最初の試作。タネから島と生き物を生成する収集RPG | 約11.3KB |

ビルド済みの `dist/<名前>/index.html` をブラウザで開けば遊べます。

## ビルド

```bash
cd claude
```

```bash
npm install
```

```bash
node tools/build.mjs toudaimori
```

`games/<名前>/body.html` と `*.js`（名前順に連結）を圧縮して `dist/<名前>/index.html` にまとめ、zip 後のサイズを上限の 512KB（524,288 バイト）と比べます。超えるとビルドが失敗します。

## 自動検査（ちいさな とうだいもり）

ビルド後に実行します。どちらも Playwright が必要です（`package.json` には入れていません）。

```bash
node tools/test/check-rooms.js
```

全部屋について、箱や大岩をどう押しても部屋から出られなくなる状態がないか、スイッチの仕掛けが解けるか、隣の部屋へ出た先が壁の中でないかを総当たりで調べます。

```bash
node tools/test/walk.js
```

実際の操作と同じ押しっぱなしの入力で主人公を歩かせ、敵がいる状態で草刈り・箱押し・部屋の往復ができるかを確かめます。

## 小さくする工夫（ちいさな とうだいもり）

- **絵**：16×16 のタイルは 8×8 を4枚ならべるか、左半分だけ描いて左右対称にする。村人は1つの絵から髪・ひげ・帽子を差し替えて作る。
- **文字**：8×8 のドットフォントから、台詞で実際に使っている字だけをビルド時に抜き出して埋め込む（約100字、700バイト）。
- **地図**：1部屋 10×8 マスを文字で書き、敵・仕掛け・人もその中の1文字で置く。
- **音**：音声ファイルなし。楽譜を文字列で持ち、ブラウザの発振器で鳴らす。
