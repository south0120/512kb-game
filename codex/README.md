# 512KBゲーム企画帳

**全48案。** 4秒で指が動くミクロゲームから、最後の町まで何時間も一緒に旅をするRPGまで。下の作品名を開くと、プレイヤーが迷う一手、決着のつき方、最初に作って遊べる範囲が読める。時間は完成時のプレイ目安。ここには実装前の企画を収録している。

## 最初に遊び比べたい4本

| 作りたい体験 | 最初の候補 | まず手元で動かすもの | 遊んだ人に注目したい瞬間 |
|---|---|---|---|
| 4秒で笑って次へ | [深夜のスマホ当番](ideas/rhythm.md#r01) | 猫を撮る、端子を挿す、指紋を拭く、の3問 | 二巡目、同じ命令でも配置を見て指の動きを変えるか |
| 手を止めて考える | [パキッ！ドバイショコラ](ideas/puzzle.md#p01) | 板チョコ1枚と注文3枚 | 最後の客の分を見て、最初の一折りをやり直したくなるか |
| 「わかった！」を人に話す | [圏外写真館の弟子](ideas/escape.md#e02) | 椅子2脚と、ゆっくり首を振るカメラ | 撮り損ねた一枚を見て、自分から椅子の間を走り出すか |
| 先の町まで連れていく | [鳴き線のフィールドノート](ideas/epics.md#l01) | 無人駅1つ、鳴く生き物3種、鉄橋の群れ | 同じ群れを、別の仲間の声でも動かしたくなるか |

短編を最初に一本仕上げるなら『パキッ！ドバイショコラ』。紙に粒と注文を描くだけで、一折り目の面白さを確かめられる。長編に着手するなら『鳴き線のフィールドノート』の無人駅。仲間を見つける楽しさと、その仲間で道を開く楽しさを、一駅で続けて試せる。以下の48案から選ぶためのたたき台で、着手順は未定。

## 容量と参考にした棚

ゲーム化するときはHTML 1枚、外部ファイルなし、zip後524,288バイト以内。たとえば『鳴き線』は鳴き声の譜面を絵と合成音で共用し、『改札裏の九十秒』は監視映像を短いコマ列で描く。AIの文字起こしも配達アプリもゲーム内のデータで遊べる。長編の尺や容量は企画段階の想定なので、章を増やす判断は最初の場面を実際に遊び、zipサイズを測ってから行う。[リポジトリの制作条件](../README.md)

レトロゲームズの1990年の棚には、『アドベンチャーズ オブ ロロII』の隣に時代劇や野球、球団経営の作品まで並ぶ。この取り合わせを参考に、同じ小さな画面で「待って跳ぶ」「証拠を重ねる」「次の商売に備える」といった違う楽しさを選べる棚にした。[レトロゲームズ・1990年の作品一覧](https://retrogamez.net/archives/category/sales_year/1990)
